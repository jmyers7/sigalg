    MarkovChain

    Bases: StochasticProcess

    A class representing a Markov chain stochastic process.

    The constructor is not intended for direct usage. Instead, user's should call the generate class method. See the Examples section below.

    See the Notes section below for the mathematical details.

    Examples:

    >>> import numpy as np
>>> from sigalg.core import (
...     Domain,
...     ParametrizedProbabilityMeasure,
...     ProbabilityMeasure,
... )
>>> from sigalg.processes import MarkovChain

    Exhaustively enumerate all trajectories of an order-2 Markov chain of length 2 on a binary state space. The initial distribution and transition kernel are instances of ProbabilityMeasure and ParametrizedProbabilityMeasure, respectively.

    >>> S = Domain.from_sequence(size=2, variable_name="s", name="S")
>>> S_0 = Domain.from_sequence(size=2, variable_name="s_0", name="S_0")
>>> pi = ProbabilityMeasure(domain=S, mapping={0: 0.2, 1: 0.8}, name="pi")
>>> K = ParametrizedProbabilityMeasure.from_domains(
...     measure_domain=S,
...     parameter_domain=S_0,
...     mapping={
...         (0, 0): 0.4,
...         (0, 1): 0.6,
...         (1, 0): 0.7,
...         (1, 1): 0.3,
...     },
...     name="K",
... )
>>> X = MarkovChain.generate(
...     kernel=K,
...     initial_distribution=pi,
...     mode="enum",
...     length=2,
... )
>>> print(X)
Markov chain 'X':
t      0  1  2
omega
0      0  0  0
1      0  0  1
2      0  1  0
3      0  1  1
4      1  0  0
5      1  0  1
6      1  1  0
7      1  1  1

    Check that the joint distribution factors according to the Markov property.

    >>> P = X.measure
>>> np.allclose(
...     P >> X, (P >> X[0]) * (P.conditional(X[0]) >> X[1]) * (P.conditional(X[1]) >> X[2])
... )
True

    Markov chains may also be generated by passing array-like objects for the initial distribution and transition kernel.

    >>> Y = MarkovChain.generate(
...     kernel=[[0.4, 0.6], [0.7, 0.3]],
...     initial_distribution=[0.2, 0.8],
...     mode="enum",
...     length=2,
...     name="Y",
... )
>>> print(Y)
Markov chain 'Y':

omega
0      0  0  0
1      0  0  1
2      0  1  0
3      0  1  1
4      1  0  0

...     domain=S ^ 2,
...     name="pi",
...     random_state=rng,
... )
>>> K = ParametrizedProbabilityMeasure.from_rand(
...     measure_domain=S,
...     parameter_domain=S ^ 2,
...     random_state=rng,
... )
>>> Z = MarkovChain.generate(
...     kernel=K,
...     initial_distribution=pi,
...     mode="enum",
...     length=3,
...     name="Z",
... )
>>> print(Z)

    >>> Q = Z.measure.with_name("Q")
>>> np.allclose(
...     Q >> Z,
...     (Q >> Z[0, 1])
...     * (Q.conditional(Z[0, 1]) >> Z[2])
...     * (Q.conditional(Z[1, 2]) >> Z[3]),
... )

    Generate trajectories of the Poisson process by Monte Carlo simulation.

    In this implementation, trajectories are simulated until one trajectory reaches the specified max_count of events, and then the (required) user-provided index is truncated to the length of this shortest complete trajectory.

    If t_stop is the last time value in the time index, then a good choice for max_count is approximately rate * t_stop + 3 * sqrt(rate * t_stop), which is the mean of X_{rate * t_stop} (a Poisson random variable) plus 3 times its standard deviation.

    The trajectories of Poisson processes are right-continuous step functions that jump by 1 at each event time. In order to plot these trajectories accurately, the user should select a continuous time index with a sufficiently large number of points.

    A class representing a stopping time.

    The constructor is not meant to be used directly. Instead, the user should call the from_filtration class method.

    See the Notes section below for the mathematical details.

    Examples:

    >>> from math import inf
>>> from sigalg.core import Time
>>> from sigalg.processes import RandomWalk, StoppingTime

    A gambler begins with 10 units of currency in the bank and plays a game with unit stakes. The gambler has probability 0.4 of winning one unit, and probability 0.6 of losing one unit. We suppose that the money in the gambler's bank is modeled by a random walk, and that the gambler plays ten games.

    In SigAlg, we set up this random walk as follows, and generate eight random trajectories:

    >>> T = Time.discrete(start=1, stop=10)
>>> S = RandomWalk.generate(
...     mode="sim",

...     index=T,

...     random_state=42,
...     name="S",

    \[ \tau^{-t}(t) \in \mathcal{F}_t. \]
